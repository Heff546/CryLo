CryLo Testnet Launch v2

Start daemon:
./CryLo-daemon --testnet --data-dir ~/.CryLo-testnet-v2

Create wallet:
./CryLo-wallet --testnet --daemon-address=127.0.0.1:22641 --generate-new-wallet ~/.CryLo-testnet-v2/wallets/miner

Open wallet:
./CryLo-wallet --testnet --daemon-address=127.0.0.1:22641 --wallet-file ~/.CryLo-testnet-v2/wallets/miner

Daemon mining:
curl http://127.0.0.1:22641/start_mining \
  -d '{"miner_address":"YOUR_CRYLO_ADDRESS","threads_count":4}' \
  -H 'Content-Type: application/json'

Check mining:
curl http://127.0.0.1:22641/mining_status
